# しもぺいシミュレーター

ホッケー部監督「しもへい。」の深夜LINEを生き延びる、LINE風の詰めシミュレーター。
[コンサル詰めシミュレーター](https://landsknecht.jp/tsume/) の構造を参考に、見た目をLINEに寄せたもの。

## 遊び方

土曜 23:47、練習試合は 2-5 で敗戦。明日は朝6時集合。監督の既読が、ついた。

- 返信候補をタップするか、自由に文章を打って返す
- 返信が遅いと催促が飛んでくる（放置し続けると電話が鳴る）
- **メンタル** が尽きたら寝落ち、**信頼** が尽きたら戦力外
- 詰めの内容は9フェーズ各2〜3種からランダムなので毎回変わる
- 結果画面で判定・称号が出て、LINE / X でシェアできる

## 構成

ビルド不要の静的サイト。`index.html` を開けばそのまま動く。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（LINE風UI・スタート・結果・着信） |
| `style.css` | 見た目。LINEのトーク画面を再現 |
| `data.js` | しもへい。のセリフ、返信候補、エンディング |
| `app.js` | ゲーム進行・メーター・催促タイマー・判定 |
| `assets/` | アイコン画像 |

セリフを足したいときは `data.js` の `DATA.phases` に同じ形でカードを追加するだけ。
